# Telegram Business Offers

Python 3.11. Install: `pip install -r requirements.txt`.

1. Revoke the previously shared token in @BotFather and create a new one.
2. Set `BOT_TOKEN` as an environment variable on BotHost.ru (or copy `.env.example` to `.env` and set it there).
3. Enable Business Mode for the bot in @BotFather and connect the bot to your Telegram Business account with permission to reply to messages.
4. Run `python main.py`.

In a business-connected private chat send `.buy https://t.me/nft/RestlessJar-5940 2500` or `.buy https://t.me/nft/RestlessJar-5940 2500 звезд`.

The bot edits the command message to a linked offer with a Telegram NFT URL preview, if Telegram provides one. It never promises payment or transfers a gift. A Telegram link preview is generated by Telegram and cannot be guaranteed to match the official gift card. Inline keyboard custom emoji IDs are not universally supported, so standard symbols are used as a fallback.

The person accepting the offer must be the recipient of the business chat. The owner of the connected Business account is treated as the offer creator. The button links to the offer creator's Telegram profile. The offer is not an official Telegram Marketplace transaction.
